A — Terminal Takeover

The console hijacks itself. Commands type themselves at human speed — with hesitations and typos. Fake intrusion data streams in (whoami, ssh keys, route enumeration). After 8–10s a "connection reset" message appears and control returns. 100% behavioral, zero CSS animations.

B — DOM Decay

Walks every visible text node on the live page and progressively replaces characters with zalgo, binary, and symbol noise — entropy spreading from random hotspots outward. The page literally rots. After ~15s it optionally regenerates, or requires refresh. The content itself becomes the effect.

[ page fragments mid-scatter ]
↑ DOM tiles explode outward

C — Reality Shatter

Clones the live DOM into a grid of tile-sized divs, then animates them outward in an explosion using random trajectories and rotations — leaving a void. After the scatter, tiles magnetize back and the page reforms. Like breaking and reconstructing a mirror. Cinematic, one-shot, fully reversible.

These can also be combined — e.g. A + B: the terminal takeover triggers DOM decay simultaneously
